# BS0013 Resources

Supplementary resources for **BS0013 Data Structures**. Use this folder for references, visualizations, tutorials, and other material that supports the lectures and practical work.

## Available resources

### [Free Data Structures and C++ Resources](free-data-structures-cpp-resources.md)

A curated list of freely accessible resources for this course, including:

- **cppreference** for precise C++ and STL documentation;
- **LearnCpp** for refreshing C++ language concepts;
- **VisuAlgo**, **OpenDSA**, and **David Galles visualizations** for interactive data-structure and algorithm traces;
- **MIT 6.006** and **Princeton Algorithms** for deeper study of algorithms, complexity, and data structures;
- **C++ Core Guidelines** for modern C++ design and ownership practices;
- **Compiler Explorer** for small C++ experiments and compiler investigation.

The resource guide also contains a **topic-to-resource map** covering complexity, arrays, linked lists, stacks, queues, sorting, heaps, trees, hashing, graphs, STL containers, and modern C++.

## How to use these resources

Course lectures and labs remain the primary guide for what you are expected to learn. External resources are most useful for getting a second explanation, visualizing an operation, checking C++ library behavior, or exploring a topic in greater depth.

When working on a lab, use external material to understand the concept and documentation rather than copying a completed implementation. You should be able to explain the representation, invariants, operations, and complexity of the code you submit.

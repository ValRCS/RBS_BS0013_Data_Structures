1. Objects and addresses

An object has a type, value, storage and lifetime. Equal values can belong to distinct objects. &x obtains an address; sizeof(x) measures the object's size in bytes, not the amount of dynamic storage it may own. The following addresses are symbolic; separate local variables need not have consecutive addresses.

Prediction: if two integers store the same number, are they the same object?

No. Identity and value are separate.

2. Pointer playground

A pointer is itself an object containing a pointer value. int* p = &a; stores an address; *p designates the target. A pointer can be copied or reassigned, unlike a reference binding. Assignment through a reference changes the referred-to object.

Choose a preset and predict each effect before stepping, or manipulate the two pointers freely. Solid links designate live objects; dashed links indicate expired targets. The diagram and text both show state.

3. Lifetime simulator

Automatic objects normally end their lifetimes when their block exits. Dynamically allocated objects have a separate lifetime. An external raw pointer does not keep its target alive. The simulator retains a symbolic record of expired objects, not a real valid address. It blocks invalid operations rather than executing undefined behavior.

Load Nested scope, step into the block, declare an int, read it, then leave the scope. Predict the next read. The two pointer variables remain in the outer scope throughout this model.

4. Dynamic memory laboratory

new int{42} creates a dynamic object; compatible delete releases it. Pointer reassignment does not release storage. Deletion through a valid pointer to a compatible allocation ends the object's lifetime but does not null aliases. Deleting nullptr is harmless.

Ownership is a programmer-assigned responsibility, not a property enforced by raw pointers. This closed model counts a live allocation with no pointer to it as unreachable. A live allocation may still be reachable but have no designated owner. Addresses are never reused here to keep identity visible.

Why not implement all ownership manually in production?

RAII associates resource management with object lifetime. Week 3 introduces resource-owning classes and dynamic arrays; later weeks build on that model.

5. Memory error detective

Identify the broken lifetime, access or ownership condition and choose a repair. Each scenario is an independent formative example, not an assessed lab solution.

6. Node chain playground

struct Node {
    int value;
    Node* next = nullptr;
};

Links store pointer values, not copies of payloads. These are modeled automatic nodes with non-owning links. Change next or head, or select a new current pointer. Ending a lifetime is a symbolic external event, not delete. Try a disconnected node and compare live versus reachable counts. The Shared suffix preset lets you compare traversal starting at A and D.

For a valid null-terminated chain of n nodes, ordinary iterative traversal costs Θ(n) time and Θ(1) auxiliary space. The node storage itself is not auxiliary traversal storage. The simulator separately tracks visited identities to stop cycles and dangling links; that diagnostic bookkeeping is not part of the modeled ordinary traversal.

Optional C++20 implementation notes

Ten independent examples; compile and run each separately.

Separate objects and symbolic vs real addresses C++20 · standalone

Shows two equal values and distinct addresses; actual addresses vary.

#include <iostream>

int main() {
    int a=7,b=7; std::cout << a << ' ' << b << ' ' << (&a != &b) << '\n';
}

Open source · Expected output: 7 7 1 (whitespace normalized).

Address-of and dereference C++20 · standalone

The write changes the designated object.

#include <iostream>

int main() {
    int x=11; int* p=&x; *p=19; std::cout << x << '\n';
}

Open source · Expected output: 19 (whitespace normalized).

Independent pointer objects C++20 · standalone

Reassignment changes one pointer, not its alias.

#include <iostream>

int main() {
    int a=6,b=8; int* p=&a; int* q=p; p=&b; *q=14; std::cout << *p << ' ' << a << '\n';
}

Open source · Expected output: 8 14 (whitespace normalized).

Reference binding versus pointer reseating C++20 · standalone

Reference assignment modifies its original target.

#include <iostream>

int main() {
    int a=1,b=9; int& r=a; int* p=&a; r=b; p=&b; *p=4; std::cout << a << ' ' << b << '\n';
}

Open source · Expected output: 9 4 (whitespace normalized).

Safe scope observation C++20 · standalone

Reset the observer before its target dies.

#include <iostream>

int main() {
    int* p=nullptr; { int x=23; p=&x; std::cout << *p << '\n'; p=nullptr; } std::cout << (p==nullptr) << '\n';
}

Open source · Expected output: 23 1 (whitespace normalized).

Controlled scalar allocation C++20 · standalone

Exactly one compatible release.

#include <iostream>

int main() {
    int* p=new int{13}; std::cout << *p << '\n'; delete p; p=nullptr; std::cout << (p==nullptr) << '\n';
}

Open source · Expected output: 13 1 (whitespace normalized).

Owner and observer C++20 · standalone

Only the designated responsible pointer releases; observer stops use first.

#include <iostream>

int main() {
    int* owner=new int{31}; int* observer=owner; std::cout << *observer << '\n'; observer=nullptr; delete owner; owner=nullptr;
}

Open source · Expected output: 31 (whitespace normalized).

Non-owning links C++20 · standalone

Automatic nodes are not deleted through next.

#include <iostream>

int main() {
    struct Node { int value; Node* next=nullptr; }; Node a{4},b{9}; a.next=&b; std::cout << a.next->value << '\n';
}

Open source · Expected output: 9 (whitespace normalized).

Linear traversal C++20 · standalone

Time Θ(n); auxiliary traversal storage Θ(1).

#include <iostream>

int main() {
    struct Node { int value; Node* next=nullptr; }; Node a{2},b{5},c{8}; a.next=&b; b.next=&c; int sum=0; for(const Node* cur=&a;cur;cur=cur->next) sum+=cur->value; std::cout << sum << '\n';
}

Open source · Expected output: 15 (whitespace normalized).

Reachability is not lifetime C++20 · standalone

Skipped node still exists.

#include <iostream>

int main() {
    struct Node { int value; Node* next=nullptr; }; Node a{3},b{6},c{9}; a.next=&b; b.next=&c; a.next=&c; std::cout << a.next->value << ' ' << b.value << '\n';
}

Open source · Expected output: 9 6 (whitespace normalized).

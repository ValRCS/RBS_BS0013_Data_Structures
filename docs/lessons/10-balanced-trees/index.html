1. Why balance matters

Every key in a BST’s left subtree is smaller, every key in its right subtree larger. Search takes O(h). Sorted insertion can create a chain of height n. AVL guarantees logarithmic height while preserving the same ordered set. Compare the two trees below.

int main(){std::unique_ptr<Node>a,b;for(int k:{10,20,30,40,50,60,70})add(a,k);for(int k:{40,20,60,10,30,50,70})add(b,k);std::cout<<visits(a.get(),70)<<" "<<visits(b.get(),70)<<"\n";}

2. AVL anatomy

Node-count convention: empty height 0, leaf height 1. h(v)=1+max(h(left),h(right)); BF(v)=h(left)−h(right). Every node must satisfy |BF|≤1. Cached heights must equal actual heights; strict global ordering, reachability and recorded size are separate invariants.

Child heights 2 and 1 imply h=3 and BF=+1; child heights 3 and 1 imply imbalance.

4. Single rotations

A right rotation promotes the left child; a left rotation promotes the right child. Preserve the middle subtree and replace the owning link. Refresh the former root before the pivot. Rotations allocate no nodes, change a constant number of links and preserve inorder. A standalone rotation is not guaranteed to balance an arbitrary tree.

Dashed blue = current node; orange = middle subtree; red = imbalance from cached child heights.

8. Complexity laboratory

Minimum node count N(h)=1+N(h−1)+N(h−2), N(0)=0, N(1)=1. Fibonacci growth implies logarithmic AVL height. Minimum binary tree height is ceil(log₂(n+1)); maximum AVL height is largest h with N(h)≤n.

9. Alternative strategies

AVL enforces a strict height bound. Red-Black trees use colors, black root and NIL leaves, no consecutive red nodes, and equal black counts on root-to-NIL paths. Search and updates have logarithmic worst-case bounds. Splay trees move accessed nodes toward the root: logarithmic amortized search, linear worst-case individual search.

TreeWorst searchAmortized searchMetadata
AVLO(log n)O(log n)Height or BF
Red-BlackO(log n)O(log n)Color
SplayO(n)O(log n)None for balancing

std::set and std::map guarantee logarithmic relevant operations, but C++ does not mandate Red-Black implementation. Prefer unordered containers when ordering is unnecessary and expected constant lookup is suitable.

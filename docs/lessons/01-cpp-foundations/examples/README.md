# Week 1 independent C++20 demos

From this directory: `g++ -std=c++20 -Wall -Wextra -Wpedantic hello.cpp -o /tmp/week01-hello && /tmp/week01-hello`. Replace the filename to run another example. Each file has its own `main`. These are supplemental examples, not lab solutions.
